# Care Guide BD — Product & UI Specification (`PRODUCT.md`)

- **Purpose:** Backend engineering assessment interface for Care Guide BD demonstrating JWT Authentication, Role-Based Access Control (`user` vs `admin`), Private Notes CRUD, Public Posts, Admin User Management (including `keepData` deletion prompt), and MongoDB Aggregation Scenarios 1 & 2.
- **UI Mode:** Restricted deterministic functional layout (Tailwind CSS tables, forms, tabs, and modals). No decorative bloat.
